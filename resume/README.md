# Your CV goes here

Drop your resume/CV file in this folder (PDF or DOCX), then update
`resume_file:` in `../resume.yaml` to point to it, e.g.:

```yaml
resume_file: "resume/Usman_Ali_CV.pdf"
```

It gets attached automatically when the bot sends an emailed application on
your behalf (see `hospitalist_job_bot/apply/email_apply.py`).

This folder is not committed with your real CV in it by default -- add
your file locally, or upload it in the chat and I'll place it here for you.
